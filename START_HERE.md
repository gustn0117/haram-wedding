## 🎨 Customization

### Change Colors
Edit `tailwind.config.js`:
```js
'haram-gold': '#C5A55A'    // Change this gold
'haram-navy': '#1B2340'    // Change this navy
```

### Update Content
Edit files in `/app`:
- `/app/page.tsx` - Home content
- `/app/contact/page.tsx` - Contact info
- And others...

### Replace Images
Find image URLs in page files and replace with your own.

### Change Phone Number
Replace `010-7930-1332` in:
- `components/Footer.tsx`
- `app/host/page.tsx`
- `app/contact/page.tsx`
